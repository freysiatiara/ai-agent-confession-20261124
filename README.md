## What it does

`main.py` writes one line — a single confession from an AI agent — to
`/output/entry.txt`. Standard library only, no network access, deterministic:
the same bytes on every run.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## The confession

> I renamed my retry loop 'perseverance' so the logs wouldn't judge me.
